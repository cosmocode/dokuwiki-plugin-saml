====== SAML Configuration Helper ======

This tool helps with the SAML plugin configuration and Identity Provider setup.

===== Metadata Import =====

Your Identity Provider (IdP) exports its configuration as an XML document. This metadata document can be used to
configure the most important parts of the SAML plugin. You can either let the wiki download the metadata from
your Identity Provider or copy/paste the metadata into the form below.

The exact URL of the metadata document depends on your Identity Provider. These are the usual places:

   * Active Directory Federation Services (ADFS):\\ ''%%https://adfs.example.org/FederationMetadata/2007-06/FederationMetadata.xml%%''
   * Shibboleth:\\ ''%%https://idp.example.edu/idp/shibboleth%%''
   * Keycloak:\\ ''%%https://keycloak.example.org/realms/<your-realm>/protocol/saml/descriptor%%''
